# AmritaGO 文档

AmritaGO 当前处于 Alpha 阶段，文档描述的是当前版本；功能、配置格式及插件接口可能随测试反馈变化。

- [部署指南](deployment.md)：通过 `uvx` 运行、从源码启动与打包。
- [配置指南](configuration.md)：模型 Provider、凭据存储、工作区和环境变量。
- [Agent 预设指南](agents.md)：内置预设、项目级/用户级预设和示例 Agent。
- [Skill 系统](skills.md)：发现目录、元数据、启用状态和按需加载机制。
- [插件指南](plugins.md)：外部插件的安装、开发接口与安全边界。

如遇到问题，请通过仓库的 Issue 模板反馈，并先移除日志中的密钥、令牌和个人信息。
